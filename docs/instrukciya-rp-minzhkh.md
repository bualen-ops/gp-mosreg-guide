## 1. Кто такой РП

**РП — руководитель проекта** по объекту государственной программы в сфере ЖКХ Московской области.

РП ведёт объект от исходных данных и ПИР до ввода, отвечает министерству за сроки, лимиты, качество и статус. На практике это стык трёх сторон:

| Сторона | Что РП делает |
|---|---|
| ОМСУ | сверка потребности, охвата, мощности, сроков благоустройства |
| Подрядчик / проектная организация | контроль СМР, исполнительной, КС, авансов, недопоставок |
| МинЖКХ МО (и при необходимости федеральный уровень) | отчётность, письма о переносе срока, согласование лимитов ГП, участие в штабах |

Типовой контур: **проектный офис МинЖКХ** контролирует цикл «изыскания → ПСД → МОГЭ → контрактация → СМР → ввод». РП — оператор объекта внутри этого контура.

В реестре вводных 2026 в дополнительном источнике закреплены, в частности: Кострыгин М.С., Максимов, Салякин Д.В., Бомштейн А.Г., Васько А.Я., Маев, Петропавловский.

## 3. Что РП обязан держать в актуальном состоянии

Еженедельно (к штабу / срезу МинЖКХ) по каждому объекту:

1. **Готовность, %** — фактическая стадия СМР, не «ожидание».
2. **Перенос срока** — только `да` или `нет`. Если `да`, в комментарии: зачем, на какую дату, есть ли письмо в МинЖКХ.
3. **Комментарий РП** — см. шаблон ниже.
4. **ПСД / МОГЭ** — да / нет / не требуется; номер заключения; плановая дата выхода, если объект в экспертизе.
5. **Контракт** — номер, дата, подрядчик. Ноль и пустышка не считаются контрактацией.
6. **Лимиты vs оплата** — если касса не бьётся с ГП, заполнить комментарий несовпадений и инициировать корректировку ГП.
7. **Письма в МинЖКХ** — перенос срока, увеличение лимита по МОГЭ, расторжение контракта: номер/дата в комментарии.

## 4. Как писать комментарий РП

Рабочий формат, который уже встречается в реестре и читается штабом:

```
РП Фамилия И.О. на ДД.MM.ГГГГ
Стрг — N%.
Контракт: дата, цена, срок СМР, срок полной оплаты.
МОГЭ: дата / номер / стоимость (если есть удорожание — %).
Статус: что сделано / что осталось.
Блокер: земля / сети / РС / ГПР / лимиты ГП / подрядчик.
Следующая дата: КС-2 / закрытие / ввод.
```

### Хорошие формулировки (по реальному реестру)

- `Стрг - 50%. Плановые работы.`
- `Стрг- 60%. Осталось выполнить благоустройство и врезку в коллектор водоканала.`
- `Стрг - 2%. Проблема с землёй. Сервитут по участку частных лиц. Вероятность реализации в 2026 - 10%.`
- `работы выполнены, для закрытия КС-2 требуется увеличение лимитов ГП по заключению МОГЭ`
- `Направлено письмо в МинЖКХ о переносе срока для выполнения благоустройства после схода снега.`

### Чего избегать

- Только ФИО в поле комментария (`РП Максимов Павел Сергеевич`) — это не статус.
- Голая цифра (`23`) без единиц и смысла.
- Комментарий без даты среза.
- «Плановые работы» при `перенос срока = да` без причины переноса.

## 5. Типовые ситуации и действия РП

### Срыв / перенос срока

1. Выставить «Перенос срока» = да.
2. В комментарии: причина, новая дата, благоустройство после зимы / земля / сети / экспертиза.
3. Письмо в МинЖКХ; реквизиты письма оставить в комментарии.

### Удорожание после МОГЭ

1. Зафиксировать смету МОГЭ и % к ГП.
2. Не закрывать КС-2, пока не увеличены лимиты ГП.
3. Запустить корректировку ГП; в поле корректировок — факт/план.

### Подрядчик не закрывает объёмы / аванс

1. Оценка УТНКР: объёмы и материалы vs аванс.
2. Претензия, при необходимости расторжение.
3. В комментарии: недосдача, решение администрации, срок нового контракта (например 14–21 день).

### Объект в МОГЭ

1. «Наличие МОГЭ» = нет, заполнить плановую дату выхода.
2. Комментарий: что загружено (изыскания, РС, ОКН, ГПР, сети ЭС).
3. После заключения — номер МОГЭ, сметная стоимость, в т.ч. ПИР.

### Нет контракта СМР

В справочнике объект без реального номера контракта считается **не законтрактованным**. РП не подставляет `0` вместо номера.

## 6. Как пользоваться витриной (для РП и аппарата)

1. Открыть https://gp.mosreg.alenos.ru
2. Отфильтровать ОМСУ / год ввода / тип / подрядчика.
3. В карточке смотреть блок **Статус** и **Комментарий РП**.
4. Если ФИО РП пустое в карточке — оно часто есть только в доп. источнике (`РП (доп. источник)`).
5. Выбрать объект → скачать справку `.html` / `.doc` для штаба (поля РП попадают в справку).
6. Сводка по муниципалитетам — `dashboard.html` на тех же данных.

Обновление витрины: таблицы читаются напрямую (CSV Google Sheets). Отдельный прогон `build_data.py` нужен только если обновляете статический `data.json` из Excel `Реестр_Вводных_2026.xlsx`.

## 7. Границы ответственности (чтобы не путать поля)

| Поле | Чья зона | Не путать с |
|---|---|---|
| Комментарий руководителей проектов | РП, оперативный статус | комментарием несовпадений оплат |
| Комментарий (доп. лист) | РП, развёрнутый статус по контракту | основным комментарием, если они расходятся — править оба |
| Колонка «РП» | закрепление объекта за человеком | комментарием |
| Комментарий несовпадений оплат и лимитов ГП | финансы / ГП | стройготовностью |
| Перенос срока | решение по графику | % готовности |

Если основной и доп. комментарий расходятся, для штаба приоритет у **более свежей даты среза** в тексте. Дату в комментарии ставить обязательно.

## 8. Чек-лист перед штабом МинЖКХ

- [ ] У объекта есть ФИО РП
- [ ] Готовность заполнена и совпадает с комментарием
- [ ] Если срок под риском — флаг переноса = да и есть причина
- [ ] Комментарий с датой среза, блокером и следующей датой
- [ ] ПСД/МОГЭ не «пустые», если объект не на этапе «не требуется»
- [ ] Контракт либо реальный номер, либо явно «нет контракта»
- [ ] Письма в МинЖКХ (перенос, лимиты) отражены в комментарии
- [ ] Витрина / справка открывается и показывает тот же текст, что в таблице
